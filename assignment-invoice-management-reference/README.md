# Invoice Management – Assignment Reference

This reference follows the supplied Invoice Management documentation and the authorized reference repository.

## Main workflow
1. Open Manage Estimate.
2. Select the required estimate.
3. Open Generate Invoice.
4. Enter customer Email ID.
5. Enter Amount Paid.
6. Generate the invoice.
7. Download the generated invoice PDF.
8. Send the invoice PDF to the entered email address.

## Invoice information
- Invoice Number
- Estimate ID
- Chain ID
- Company Name
- Service
- Quantity
- Cost per Quantity
- Amount Payable
- Amount Paid
- Balance
- Date of Payment
- Date of Service
- Delivery Details
- Email ID

## Management operations
- View invoices
- Search by Invoice Number, Estimate ID, Chain ID and Company Name
- Edit invoice information
- Delete invoices
- Generate/download invoice PDF
- Send invoice PDF by email

## Validation
- Estimate information must be available.
- Email ID is required.
- Amount Paid cannot be negative.
- Amount Paid cannot be greater than Amount Payable.
